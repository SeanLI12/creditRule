คริกเก็ต

อัปเดตครั้งสุดท้าย: 01/12/2025

กฎทั่วไป
  • หากการแข่งขันถูกยกเลิกก่อนที่การแข่งขันจะเริ่มต้นขึ้น ตลาดทั้งหมดจะถือเป็นโมฆะ เว้นแต่การแข่งขันนั้นจะมีการเล่นซ้ำภายใน 48 ชั่วโมงนับจากเวลาเริ่มต้นเดิม
  • หาก “โอเวอร์” ไม่ได้เล่นจบ ทุกตลาดที่เกี่ยวข้องกับโอเวอร์นั้นจะถือเป็นโมฆะ เว้นแต่โอกาส (innings) จะสิ้นสุดลงโดยธรรมชาติ เช่น การประกาศปิดโอกาส หรือทีมถูกทำให้ “ออลเอาท์” เป็นต้น
  • เว้นแต่จะมีการระบุไว้เป็นพิเศษในตลาดใดตลาดหนึ่ง หากไม่มีผลการแข่งขันอย่างเป็นทางการ การเดิมพันทั้งหมดจะถือเป็นโมฆะ
  • ในกรณีที่การแข่งขันได้รับผลกระทบจากสภาพอากาศที่ไม่เอื้ออำนวย การเดิมพันจะถูกตัดสินตามผลการแข่งขันอย่างเป็นทางการ
  • สำหรับตลาดที่เกี่ยวข้องกับนักตี (batsman) จะตัดสินจากจำนวน “รัน” ที่นักตีคนนั้นทำได้ หากการแข่งขันเสมอ และกติกาการแข่งขันไม่มีการกำหนดผู้ชนะ หรือหากผู้ชนะถูกตัดสินด้วยการ “โยนเหรียญ” หรือ “จับฉลาก” ตลาดที่ยังไม่ตัดสินทั้งหมดจะถือเป็นโมฆะ
  • หากตลาดเปิดด้วยคะแนนที่ไม่ถูกต้องซึ่งมีผลอย่างชัดเจนต่อราคา เราขอสงวนสิทธิ์ยกเลิกการเดิมพัน
  • ในการแข่งขันแบบ Limited Overs (เช่น T20 หรือ ODI) ตลาด “ผู้ชนะ” จะรวมผลที่ได้จาก “Super Over” ด้วย แต่ Super Over จะไม่ถูกนับรวมในตลาดอื่น ๆ เว้นแต่จะระบุไว้เป็นพิเศษ
  • โทษ 5 รัน (5-run penalties) จะไม่ถูกนับรวมในตลาดที่เกี่ยวข้องกับ “โอเวอร์” หรือ “ลูก” ใด ๆ (ตลาดที่รวมหลายโอเวอร์ไม่อยู่ภายใต้กฎข้อนี้)
  • Twenty20 และ ODI จะต้องมีการเล่นอย่างน้อย 90% ของจำนวนโอเวอร์ทั้งหมดที่จัดสรรไว้สำหรับหนึ่งโอกาส ณ เวลาที่มีการวางเดิมพันเพื่อให้ตลาดนั้นสามารถตัดสินผลได้เว้นแต่โอกาสนั้นจะสิ้นสุดลงโดยธรรมชาติ
  • หากผู้เล่นถูกไล่ออกจากสนามจะถือว่าเป็นการ“รีไทร์เอาท์” และจะถูกตัดสินว่าเป็นวิเก็ต
  • เมื่อผู้เล่นออกจากสนามและมีผู้เล่นสำรองลงมาแทน การออกจากสนามในลักษณะนี้ จะไม่ถือว่าเป็นวิเก็ต หากผู้เล่นคนนั้นไม่กลับเข้าสู่สนามในภายหลัง ผลการแข่งขันสุดท้ายจะถูกตัดสินตามสถานการณ์ ณ เวลาที่ผู้เล่นออกจากสนามนั้น เมื่อมีผู้เล่นสำรองถูกส่งลงสนาม สำหรับการตัดสินผลการเดิมพัน จะถือว่าผู้เล่นทั้งสองคน ทั้งผู้เล่นที่ถูกเปลี่ยนออกและผู้เล่นสำรองที่ลงมาแทน ได้มีส่วนร่วมในการแข่งขันอย่างเต็มรูปแบบทั้งคู่
  • รันบทลงโทษที่เพิ่มไว้ในยอดรวมของทีมหลังจากเริ่มต้นอินนิ่งของอีกทีมจะไม่นำไปนับในการตัดสินตลาดในอินนิ่งก่อนหน้า
  • สำหรับฮันเดรด หนึ่งโอเวอร์จะประกอบด้วยการขว้างลูกที่ถูกต้อง 5 ลูก ดังนั้นหนึ่งอินนิ่งเต็มจะมีทั้งหมด 20 โอเวอร์ กฎอื่นๆ ทั้งหมดยังคงเหมือนกับรูปแบบเกมจำกัดโอเวอร์อื่นๆ
  • ถ้าแมตช์ถูกสร้างในรูปแบบที่ผิด (เช่น T20 แทนที่จะเป็น List A) การเดิมพันจะเป็นโมฆะและจะมีการสร้างแมตช์ใหม่
  • หากมีการส่งตลาดสดด้วยผลทอยที่ไม่ถูกต้องและทีมที่ไม่ถูกควรจะตีลูกก่อน ตลาดจะยังคงตัดสินผลตามปกติในระหว่างและหลังจบอินนิ่งของทีมนั้น

ตลาดแมตช์ทั่วไป

1 X 2

  • ทายว่าทีมใดจะเป็นผู้ชนะในแมตช์นั้น
  • ในกรณีที่การแข่งขันได้รับผลกระทบจากสภาพอากาศที่ไม่เอื้ออำนวย การเดิมพันจะถูกตัดสินตามผลลัพธ์อย่างเป็นทางการ
  • ในกรณีที่เสมอ หากกฎการแข่งขันอย่างเป็นทางการไม่ได้ระบุผู้ชนะจะใช้กฎเดดฮีท
  • ในรายการแข่งขันที่โบว์ลออฟหรือซูเปอร์โอเวอร์เป็นตัวกำหนดผู้ชนะ จะตัดสินตามผลลัพธ์อย่างเป็นทางการ
  • ในการแข่งขันประเภท First Class หากผลอย่างเป็นทางการออกมาเป็น “เสมอ” การเดิมพันจะถูกตัดสินเป็น เดดฮีทระหว่างทั้งสองทีม ส่วนการเดิมพันที่แทง “เสมอ” จะถือว่าแพ้
  • หากการแข่งขันถูกยกเลิกเนื่องจากปัจจัยภายนอก การเดิมพันจะเป็นโมฆะยกเว้นมีการประกาศผู้ชนะตามกฎการแข่งขันอย่างเป็นทางการ

การแข่งขันแบบเสมอ

  • ทายว่าการแข่งขันจะจบลงด้วยผลเสมอหรือไม่
  • สำหรับการแข่งขันประเภท First Class ผล “เสมอ” จะเกิดขึ้นเมื่อทีมที่ตีเป็นลำดับที่สองถูกทำให้ “ออกครบ” ในอินนิ่งที่สองโดยมีคะแนนเท่ากันกับอีกทีมการเดิมพันจะตัดสินเป็น “ใช่ ” หากการแข่งขันต้องตัดสินด้วยซูเปอร์โอเวอร์

ผู้ชนะ

  • ทายว่าทีมใดจะเป็นผู้ชนะในแมตช์ การเดิมพันจะมีให้เลือก 2 ทีมเท่านั้น
  • สำหรับการแข่งขันประเภท First Class หากผลการแข่งขันออกมาเป็น เสมอ การเดิมพันทั้งหมดจะถือเป็นโมฆะ
  • สำหรับการแข่งขันประเภท Limited Overs และ ODI หากมีการตัดสินผู้ชนะด้วย bowl off หรือ super over การเดิมพันจะตัดสินตามผลอย่างเป็นทางการของการแข่งขัน

โอกาสสองทาง

  • เดิมพันกับ 2 จาก 3 ที่มีผลลัพธ์ของแมตช์
  • หากผลออกมาเป็น เสมอ จะตัดสินตามกฎเดดฮีท
  • การเดิมพันทั้งหมดจะตัดสินตามกติกาอย่างเป็นทางการของการแข่งขัน

ทายผู้ชนะการโยนเหรียญ (และการแข่งขัน)

  • ทายว่าทีมใดจะชนะการโยนเหรียญก่อนเริ่มการแข่งขัน
  • วิธีการอื่นที่เทียบเท่ากับการโยนเหรียญ เช่น bat flip จะถือว่าเป็นการโยนเหรียญเช่นกัน
  • ตลาดนี้อาจมีการเสนอให้เดิมพันแบบรวม ทั้งผลชนะการโยนเหรียญและผลชนะการแข่งขัน

โอเวอร์ที่ชนะ

  • ทายว่าในโอเวอร์ที่เท่าใดของอินนิ่งของทีมที่ระบุไว้ การแข่งขันจะสิ้นสุดลง
  • การเดิมพันทั้งหมดจะถือเป็นโมฆะ หากไม่มีผลการแข่งขันอย่างเป็นทางการ
  • สำหรับการแข่งขันแบบ Limited Overs การเดิมพันทั้งหมดจะถือเป็นโมฆะ หากหลังจากวางเดิมพันแล้ว จำนวนโอเวอร์สูงสุดที่เป็นไปได้ถูกลดลงไม่ว่าด้วยสาเหตุใด

การนำในอินนิ่งแรก

  • ทายว่าผลต่างของจำนวนรันระหว่างอินนิ่งแรกของทั้งสองทีมในแมตช์ประเภท First Class จะเป็นเท่าใด
  • อินนิ่งแรกของทั้งสองทีมต้องแข่งขันจบสมบูรณ์ทั้งคู่ หากผลออกมาเสมอกัน จะใช้กฎเดดฮีทในการตัดสินผลเดิมพัน
  • สำหรับแมตช์ First Class ที่จบลงด้วยผลเสมอ การเดิมพันจะถือเป็นโมฆะ หากมีการขว้างลูกไม่ถึง 200 โอเวอร์ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปแล้วก่อนหน้านั้น

ผู้เล่นยอดเยี่ยมประจำแมตช์

  • ผู้เล่นยอดเยี่ยมประจำแมตช์
  • ทายว่าผู้เล่นคนใดจะได้รับการประกาศให้เป็น “ผู้เล่นยอดเยี่ยมประจำแมตช์”
  • ใช้กฎเดดฮีทหากมีผู้เล่นมากกว่าหนึ่งคนได้รับรางวัลร่วมกัน
  • หากไม่มีการประกาศผู้เล่นยอดเยี่ยมอย่างเป็นทางการ การเดิมพันทั้งหมดจะถือเป็นโมฆะ
  • การตัดสินการเดิมพันจะรวมถึงผู้เล่นทุกคนที่ลงแข่งขัน รวมถึงผู้เล่นสำรองด้วย หากผู้เล่นที่เลือกไว้ไม่ได้ลงสนาม การเดิมพันจะถือเป็นโมฆะ

ผู้เล่นคนใดทำคะแนนได้ 50/100 รัน

  • ทายว่าจะมีผู้เล่นคนใดในแมตช์ทำคะแนนได้ 50 รัน หรือ 100 รัน หรือไม่
  • คะแนนตั้งแต่ 50 รันขึ้นไป จะนับเป็น “ทำ 50” และเช่นเดียวกัน คะแนนตั้งแต่ 100 รันขึ้นไป จะนับเป็น “ทำ 100”
  • สำหรับการแข่งขันแบบ Limited Overs การเดิมพันจะถือเป็นโมฆะ หากไม่สามารถขว้างลูกได้อย่างน้อย 80% ของโอเวอร์ที่กำหนดไว้ เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปแล้วก่อนการลดโอเวอร์
  • สำหรับแมตช์แบบ First Class ที่จบลงด้วยผล เสมอ การเดิมพันจะถือเป็นโมฆะ หากมีการขว้างลูกน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปแล้วก่อนหน้านั้น

คู่เปิดที่ทำคะแนนสูงสุด

  • ทายว่าทีมใดจะทำคะแนนได้มากที่สุดก่อนที่จะเสียประตูแรก
  • หากทีมที่ตีครบจำนวนโอเวอร์ที่กำหนดไว้แล้ว, ทำคะแนนถึงเป้าหมายแล้ว, หรือประกาศจบอินนิ่งก่อนที่จะเสียประตูแรก ผลการเดิมพันจะตัดสินจากจำนวนคะแนนทั้งหมดที่ทำได้จนถึงตอนนั้น
  • ในการตัดสินผลการเดิมพัน ผู้ตีที่ “ถอนตัวเนื่องจากบาดเจ็บ”จะ ไม่นับเป็นการเสียประตู
  • สำหรับการแข่งขันแบบ Limited Overs การเดิมพันจะถือเป็นโมฆะ หากอินนิ่งของทีมใดทีมหนึ่งถูกลดลงเหลือ ต่ำกว่า 80% ของจำนวนโอเวอร์ที่กำหนดไว้ เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปแล้ว หรือสามารถตัดสินผลได้ในภายหลัง
  • สำหรับการแข่งขันแบบ First Class ที่จบลงด้วยผล เสมอ การเดิมพันจะถือเป็นโมฆะ หากมีการขว้างลูกน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปแล้วก่อนหน้านั้น
  • ในการแข่งขันแบบ First Class ตลาดนี้จะพิจารณาเฉพาะ อินนิ่งแรกของแต่ละทีมเท่านั้น

คะแนนสูงสุดของผู้ตี

  • ทายว่าผู้เล่นคนใดจะทำคะแนนได้สูงที่สุดในแมตช์
  • กติกา: สำหรับการแข่งขันแบบ Limited Overs การเดิมพันจะถือเป็นโมฆะ หากไม่สามารถขว้างลูกได้อย่างน้อย 80% ของโอเวอร์ที่กำหนดไว้ เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปแล้วก่อนการลดโอเวอร์
  • สำหรับแมตช์แบบ First Class ที่จบลงด้วยผล เสมอ การเดิมพันจะถือเป็นโมฆะ หากมีการขว้างลูกน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปแล้วก่อนหน้านั้น ทั้งนี้จะใช้กฎเดดฮีทหากมีผู้เล่นมากกว่าหนึ่งคนทำคะแนนสูงสุดเท่ากัน

ผู้ตีที่ทำคะแนนสูงสุด

  • ทายว่าผู้เล่นคนใดจะทำคะแนนได้มากที่สุดในแมตช์
  • ผลของตลาดนี้จะตัดสินจากผู้ตีที่ทำคะแนนส่วนตัวได้สูงที่สุดในแมตช์นั้น
  • สำหรับการแข่งขันแบบ Limited Overs การเดิมพันจะถือเป็นโมฆะ หากไม่สามารถขว้างลูกได้อย่างน้อย 50% ของโอเวอร์ที่กำหนดไว้ในอินนิ่งใดอินนิ่งหนึ่ง ณ เวลาที่วางเดิมพัน เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศไม่เอื้ออำนวย
  • สำหรับการแข่งขันแบบ First Class การเดิมพัน “Top Batter” จะพิจารณาเฉพาะ อินนิ่งแรกของแต่ละทีมเท่านั้น และจะถือเป็นโมฆะหากมีการขว้างลูกน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปแล้วก่อนหน้านั้น
  • หากผู้เล่นถูกระบุชื่อไว้ในตอนโยนเหรียญแต่ภายหลังถูกถอดออกและแทนที่ด้วยผู้เล่นสำรองจากกรณี concussion sub (เปลี่ยนตัวเนื่องจากการกระทบกระเทือน) ทั้งผู้เล่นเดิมและผู้เล่นที่เข้ามาแทนจะถือว่า “มีส่วนร่วมในการแข่งขัน” สำหรับการตัดสินผลเดิมพัน
  • หากผู้ตีไม่ได้ออกมาตี แต่มีชื่ออยู่ในรายชื่อผู้เล่นตัวจริง (Starting XI) การเดิมพันในผู้เล่นคนนั้นจะยังคงมีผลอยู่ หากมีผู้เล่นถูกเปลี่ยนตัวเข้ามาหลังจากที่ตลาดแบบ “ระหว่างแข่งขัน” (in-play) ได้ถูกเปิดแล้ว ตลาดเดิมจะถูกปิดและตัดสินผลตามปกติ แม้ว่าผู้เล่นที่ถูกเปลี่ยนเข้ามาจะทำคะแนนสูงสุดก็ตาม ทั้งนี้อาจมีการเปิดตลาดใหม่พร้อมรายชื่อที่อัปเดตเพิ่มเติมหากผู้เล่นถูกเปลี่ยนตัวเข้ามาหลังจากอินนิ่งการตีสิ้นสุดแล้ว การเดิมพันในผู้เล่นคนนั้นจะถือเป็นโมฆะ
  • หากมีผู้เล่นสองคนหรือมากกว่านั้นทำคะแนนได้เท่ากัน จะใช้กฎเดดฮีทในการตัดสินผล และ คะแนนที่ทำได้ใน Super Over จะไม่นับรวม

  • หากมีชื่อในรายชื่อผู้เล่นตัวจริงแต่ไม่ได้ตี เดิมพันยังมีผล

  • ใช้ กฎเดดฮีทหากไม่มีผู้ชนะที่ชัดเจน

  • ในการแข่งขันแบบจำนวนโอเวอร์จำกัด หากไม่สามารถทำการแข่งขันได้ครบอย่างน้อย 80% ของโอเวอร์ที่กำหนดไว้ในอินนิ่งนั้น เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศไม่เอื้ออำนวย การเดิมพันจะถือเป็นโมฆะ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปก่อนแล้ว
  • จะนับเฉพาะโฟร์ที่มาจากการตีของผู้เล่น (ไม่ว่าจะเป็นลูกถูกกติกาหรือลูกนอกกติกา) เท่านั้น การได้แต้มจากการขว้างพลาด, การวิ่งครบสี่รอบ และแต้มพิเศษจะไม่นับรวม

จำนวนซิกส์รวมของทีม

  • ทายว่าทีมที่เป็นฝ่ายตีจะตีซิกส์ได้ทั้งหมดกี่ครั้งในอินนิ่งปัจจุบัน
  • ในการแข่งขันแบบจำนวนโอเวอร์จำกัด หากไม่สามารถทำการแข่งขันได้ครบอย่างน้อย 80% ของโอเวอร์ที่กำหนดไว้ในอินนิ่งนั้น เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศไม่เอื้ออำนวย การเดิมพันจะถือเป็นโมฆะ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปก่อนแล้ว
  • จะนับเฉพาะซิกส์ที่มาจากการตีของผู้เล่น (ไม่ว่าจะเป็นลูกถูกกติกาหรือลูกนอกกติกา) เท่านั้น การได้แต้มจากการขว้างพลาด , การวิ่งครบหกรอบ และแต้มพิเศษจะไม่นับรวม

จำนวนแต้มพิเศษรวมของทีม

  • ทายว่าจะมีแต้มพิเศษเพิ่มให้กับอินนิ่งของทีมที่ระบุไว้ทั้งหมดกี่แต้ม
  • ในการแข่งขันแบบจำนวนโอเวอร์จำกัด หากไม่สามารถทำการแข่งขันได้ครบอย่างน้อย 80% ของโอเวอร์ที่กำหนดไว้ในอินนิ่งนั้น เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศไม่เอื้ออำนวย การเดิมพันจะถือเป็นโมฆะ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปก่อนแล้ว
  • ในการแข่งขันแบบ First Class หากมีการเล่นน้อยกว่า 200 โอเวอร์ การเดิมพันจะถือเป็นโมฆะ เว้นแต่ผลการเดิมพันได้ถูกตัดสินไปก่อนแล้ว
  • ทุกลูกที่เป็น Wide, No Ball, Byes, Leg Byes และ Penalty Runs จะถูกนับรวมในผลสุดท้าย หากลูกใดมีทั้งแต้มจากการตีและแต้มพิเศษ จะนับเฉพาะแต้มพิเศษเท่านั้น แต้มพิเศษที่เกิดขึ้นใน Super Over จะไม่นับรวม
  • ในการแข่งขันแบบ First Class จะนับเฉพาะแต้มพิเศษจากอินนิ่งแรกเท่านั้น

จำนวนลูกไวด์ทั้งหมดของทีม

  • ลูกไวด์ทั้งหมดกี่ลูกจะถูกโยนโดยทีมโบว์ลิ่งที่ถูกระบุไว้
  • ในแมตช์แบบจำกัดจำนวนโอเวอร์การเดิมพันจะเป็นโมฆะถ้าหากไม่สามารถโยนได้อย่างน้อย80% ของโอเวอร์ที่กำหนดไว้ในอินนิ่งนั้น เนื่องจากปัจจัยภายนอก รวมทั้งสภาพอากาศไม่ดี เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนที่จะมีการลดจำนวนโอเวอร์
  • จำนวนรันที่เกิดจากการโยนลูกไวด์ (ยกเว้นรันลงโทษ) จะถูกนับในผลรวมสุดท้ายลูกไวด์ในการเล่นซูเปอร์โอเวอร์จะไม่นับรวม

จำนวนผู้เล่นที่ออกศูนย์รันของทีม

  • จะมีผู้เล่นกี่คนในทีมที่ทำคะแนนได้ศูนย์รัน (duck) ในอินนิ่งการตีของทีมที่ระบุไว้
  • ในแมตช์แบบจำกัดจำนวนโอเวอร์ การเดิมพันจะถือเป็นโมฆะ หากไม่สามารถโยนได้อย่างน้อย 80% ของโอเวอร์ที่กำหนดไว้ในอินนิ่งนั้น ณ เวลาที่มีการเดิมพัน เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศไม่ดี เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนที่จะมีการลดจำนวนโอเวอร์
  • ในแมตช์ประเภท First Class ที่สามารถจบด้วยผลเสมอได้ การเดิมพันจะถือเป็นโมฆะ หากมีการโยนรวมกันน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนหน้านั้น
  • Duck หมายถึง ผู้เล่นที่ถูกให้ออกโดยทำคะแนนได้ ศูนย์รัน (0 รัน) ส่วนกรณีที่ผู้เล่น “ออกเพราะบาดเจ็บจะnotไม่นับเป็นการออก
  • การออกศูนย์รัน (Duck) ที่เกิดขึ้นใน ซูเปอร์โอเวอร์ (Super Over) จะ ไม่นับรวม

จำนวนการออกเพราะวิ่งไม่ทันของทีม

  • จะมีการออกเพราะวิ่งไม่ทัน (Run Outs) ทั้งหมดกี่ครั้งในอินนิ่งนั้น
  • ในแมตช์แบบจำกัดจำนวนโอเวอร์ การเดิมพันจะถือเป็นโมฆะ หากไม่สามารถโยนได้อย่างน้อย 80% ของโอเวอร์ที่กำหนดไว้ในอินนิ่งนั้น ณ เวลาที่มีการเดิมพัน เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศไม่ดี เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนที่จะมีการลดจำนวนโอเวอร์
  • การออกเพราะวิ่งไม่ทัน (Run Outs) ที่เกิดขึ้นในซูเปอร์โอเวอร์จะไม่นับรวม
  • ในแมตช์ประเภท First Class จะนับเฉพาะการออกเพราะวิ่งไม่ทัน (Run Outs) ที่เกิดขึ้นในอินนิ่งแรกเท่านั้น

จำนวนรันรวมของทีมเป็นเลขคี่หรือเลขคู่

  • จำนวนรันรวมทั้งหมดของทีมในอินนิ่งนั้นจะเป็นเลขคี่หรือเลขคู่
  • หากอินนิ่งถูกยกเลิกหรือไม่มีผลลัพธ์ทางการ เดิมพันทั้งหมดจะถือว่าโมฆะ

อินนิ่งจะจบด้วยการตีขอบสนามหรือไม่

  • ลูกสุดท้ายของอินนิ่งจะเป็นการตีได้ขอบสนามหรือไม่
  • จะนับเฉพาะการตีขอบสนามที่เกิดจากไม้ตีของผู้เล่นเท่านั้น (ไม่ว่าจะเป็นลูกถูกกติกาหรือไม่ก็ตาม) การได้แต้มจากการขว้างพลาด (overthrows), การวิ่งครบสี่รัน (all run fours) หรือแต้มพิเศษ (extras) จะไม่นับเป็นการตีขอบสนาม
  • ในแมตช์แบบจำกัดจำนวนโอเวอร์ การเดิมพันจะถือเป็นโมฆะ หากมีการลดจำนวนโอเวอร์ที่กำหนดไว้ ณ เวลาที่มีการเดิมพัน เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศไม่ดี
  • หากการแข่งขันถูกยกเลิก (abandoned) หรือไม่มีผลการแข่งขันอย่างเป็นทางการ การเดิมพันทั้งหมดจะถือเป็นโมฆะ

ผู้เล่นใด ๆ ทำคะแนน50/100–อินนิ่ง

  • จะมีผู้เล่นทำคะแนนได้ 50 หรือ 100 รันในอินนิ่งแรกของการแข่งขันหรือไม่
  • คะแนนตั้งแต่ 50 รันขึ้นไปจะถือว่าเป็น “ห้าสิบ” และคะแนนตั้งแต่ 100 รันขึ้นไปจะถือว่าเป็น “หนึ่งร้อย”
  • ในแมตช์แบบจำกัดจำนวนโอเวอร์ การเดิมพันจะถือเป็นโมฆะ หากไม่สามารถโยนได้อย่างน้อย 80% ของโอเวอร์ที่กำหนดไว้ เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศไม่ดี เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนที่จะมีการลดจำนวนโอเวอร์
  • ในแมตช์ประเภท First Class ที่ผลออกมาเป็นเสมอ การเดิมพันจะถือเป็นโมฆะ หากมีการโยนรวมกันน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนหน้านั้น
  • ในแมตช์ประเภท First Class ตลาดการเดิมพันนี้จะหมายถึงเฉพาะ อินนิ่งแรกของการแข่งขันเท่านั้น ไม่ได้หมายถึงอินนิ่งแรกของทั้งสองทีม

โอเวอร์ทำคะแนนสูงสุด (การวิ่ง) โอเวอร์ที่ทำคะแนนได้สูงสุดในอินนิ่ง – จำนวนรัน

  • จะมีจำนวนรันทั้งหมดกี่รันที่ทำได้ในโอเวอร์ที่ทำคะแนนสูงสุดของอินนิ่งปัจจุบัน
  • ในแมตช์แบบจำกัดจำนวนโอเวอร์ การเดิมพันจะถือเป็นโมฆะ หากไม่สามารถโยนได้อย่างน้อย 80% ของโอเวอร์ที่กำหนดไว้ในอินนิ่งนั้น เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศไม่ดี เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนที่จะมีการลดจำนวนโอเวอร์
  • ในแมตช์ประเภท First Class ที่ผลออกมาเป็นเสมอ การเดิมพันจะถือเป็นโมฆะ หากมีการโยนรวมกันน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนหน้านั้น
  • คะแนนทุกแบบ รวมถึงแต้มพิเศษจะถูกนับรวมในการตัดสินผลเดิมพัน
  • ซูเปอร์โอเวอร์จะไม่นับรวม
  • สำหรับการแข่งขันรูปแบบ The Hundred หนึ่งโอเวอร์จะประกอบด้วยลูกโยนที่ถูกต้อง 5 ลูก ดังนั้นอินนิ่งเต็มหนึ่งอินนิ่งจะมีทั้งหมด 20 โอเวอร์ ส่วนกติกาอื่น ๆ ใช้เหมือนกับการแข่งขันแบบจำกัดจำนวนโอเวอร์ทั่วไป

ผู้เล่นคนสุดท้ายที่ยังไม่ออกเมื่อจบอินนิ่ง

  • ผู้ตีคนใดจะเป็นคนที่ยังไม่ออกเมื่ออินนิ่งสิ้นสุดลง
  • หากมีผู้ตีสองคนหรือมากกว่านั้นที่ยังไม่ออกเมื่อจบอินนิ่ง ผู้ชนะสำหรับการตัดสินผลการเดิมพันจะเป็น ผู้ตีคนสุดท้ายที่เผชิญหน้ากับการโยนบอล (ไม่ว่าจะเป็นลูกที่ถูกกติกาหรือไม่ก็ตาม)
  • ถ้าผู้เล่นบาดเจ็บแล้วออกจากสนาม หรือยังไม่ได้ออกมาตีเลย จะไม่นับว่าเป็น “ยังไม่ออก” และถ้ามีผู้เล่นออกมาตีเกิน 11 คน การเดิมพันจะถูกยกเลิก
  • ในแมตช์แบบจำกัดจำนวนโอเวอร์ การเดิมพันจะถือเป็นโมฆะ หากหลังจากวางเดิมพันแล้ว อินนิ่งถูกลดจำนวนโอเวอร์ลงไม่ว่าด้วยเหตุใด รวมถึงสภาพอากาศไม่ดี
  • ผู้เล่นทุกคนที่ได้ลงตีในอินนิ่งนั้นจะถูกนำมาคิดในการตัดสินผล รวมถึงผู้เล่นสำรอง

ผู้ขว้างที่เสียรันน้อยที่สุดต่อโอเวอร์

  • ผู้ขว้าง (Bowler) คนใดจะเสียรันน้อยที่สุดต่อโอเวอร์ในอินนิ่งนั้น
  • ผลของตลาดนี้จะพิจารณาจากผู้ขว้างที่มีค่าเฉลี่ยการเสียรันต่อโอเวอร์น้อยที่สุดในอินนิ่งนั้น โดยการนับรันจะตรงตามบันทึกคะแนนอย่างเป็นทางการ (scorecard) ซึ่ง ลูกไวด์ (wides) และ โนบอล (no-balls) จะถูกนับรวมเป็นรันที่เสีย แต่ บาย (byes), เลกบาย (leg byes) และ รันลงโทษ (penalty runs) จะไม่นับรวม
  • หากผู้ขว้างไม่ได้ลงขว้างแต่มีชื่ออยู่ในรายชื่อ 11 ผู้เล่นตัวจริง การเดิมพันของผู้เล่นคนนั้นจะยังคงใช้ได้ (ไม่นับเป็นโมฆะ)
  • สำหรับการเดิมพันก่อนเริ่มเกมในแมตช์ประเภท First Class จะใช้เฉพาะอินนิ่งแรกของแต่ละทีมเท่านั้น และจะถือเป็นโมฆะหากมีการโยนรวมกันน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนหน้านั้น หากผู้เล่นมีชื่อในรายชื่อก่อนเริ่มเกม (ตอนเสี่ยงเหรียญ) แล้วภายหลังถูกเปลี่ยนออกเพราะการเปลี่ยนตัวเนื่องจากการกระทบกระเทือน (concussion sub) ทั้งผู้เล่นเดิมและผู้เล่นที่มาแทนจะยังถูกนับรวม
  • หากผู้ขว้างไม่ได้ลงขว้างแต่มีชื่ออยู่ในรายชื่อ 11 ผู้เล่นตัวจริง การเดิมพันจะยังคงใช้ได้เช่นกัน และหากมีผู้ขว้างสองคนหรือมากกว่าที่มีค่าเฉลี่ยเสียรันต่อโอเวอร์เท่ากัน จะใช้กติกา Dead Heat (ถือว่าผลเสมอ แบ่งอัตราจ่ายตามสัดส่วน)
  • รันที่เสียในซูเปอร์โอเวอร์ (Super Over) จะไม่นับรวม

  • ทายว่าผู้ตีคนใดจะเป็นคนต่อไปที่ถูกให้ออก (ถูกทำให้พ้นจากการตี)
  • หากผู้ตีคนใดคนหนึ่ง ออกจากเกมเพราะบาดเจ็บ (retired hurt) หรือ ผู้ตีที่อยู่ในสนามไม่ตรงกับรายชื่อที่ระบุไว้ในการเดิมพัน การเดิมพันของผู้ตีทั้งสองคนจะถือเป็น โมฆะ
  • หากไม่มีผู้เล่นคนใดถูกให้ออกเพิ่มเติม (ไม่มีวิเก็ตตกอีก) การเดิมพันทั้งหมดจะถือเป็น โมฆะ

ขอบสนามถัดไป – สี่หรือหกรัน

  • ขอบสนาม (Boundary) ถัดไปจะเป็นการตีได้ สี่รัน (Four) หรือ หกรัน (Six)?
  • หากไม่มีการตีขอบสนามเพิ่มเติมในอินนิ่งนั้น การเดิมพันจะถือเป็น โมฆะ
  • จะนับเฉพาะการตีขอบสนามที่เกิดจากไม้ตีของผู้เล่นเท่านั้น (ไม่ว่าจะเป็นลูกที่ถูกกติกาหรือไม่ก็ตาม) การได้แต้มจากการขว้างพลาด (Overthrows), การวิ่งครบสี่รัน (All run fours) หรือแต้มพิเศษ (Extras) จะไม่นับเป็นขอบสนาม
  • ในแมตช์แบบจำกัดจำนวนโอเวอร์ การเดิมพันจะถือเป็นโมฆะ หากจำนวนโอเวอร์ทั้งหมดถูกลดลงเหลือน้อยกว่า 80% ของจำนวนสูงสุดที่กำหนดไว้ ณ เวลาที่มีการเดิมพัน เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนการลดโอเวอร์
  • ในแมตช์ประเภท First Class ที่ผลออกมาเป็นเสมอ การเดิมพันจะถือเป็นโมฆะ หากมีการโยนรวมกันน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันจะถูกตัดสินไปแล้วก่อนหน้านั้น
  • การตีขอบสนามใน ซูเปอร์โอเวอร์ (Super Over) จะ ไม่นับรวม

ใครจะทำถึงจำนวนรันที่กำหนดก่อน

  • ผู้ตีคนใดจะทำคะแนนถึงจำนวนรันที่กำหนดก่อน
  • หากไม่มีผู้ตีคนใดทำถึงจำนวนรันที่กำหนด ตลาดนี้จะตัดสินเป็น “ไม่มีผู้ใด” (Neither)
  • ในแมตช์แบบจำกัดจำนวนโอเวอร์ หากหลังจากวางเดิมพันแล้วอินนิ่งถูกลดจำนวนโอเวอร์ลง และในตอนนั้น ยังไม่มีผู้ตีคนใดถึงรันที่กำหนด และ ยังมีผู้ตีอย่างน้อยหนึ่งคนที่ยังไม่ออก → การเดิมพันเป็นโมฆะ ยังไม่มีผู้ตีคนใดถึงรันที่กำหนด แต่ทั้งสองคนถูกให้ออกแล้ว → การเดิมพันยังคงใช้ได้
  • เดิมพันโมฆะหากผู้เล่นที่ระบุใดไม่ได้เปิดตีลูกในอินนิ่งของเขา

ยอดรวมสูงสุดในโอเวอร์ที่ 1

  • ทีมใดจะทำคะแนนได้มากที่สุดในโอเวอร์แรกของอินนิ่ง
  • โอเวอร์แรกต้องจบลงก่อนเพื่อให้การเดิมพันใช้ได้ เว้นแต่ผลจะถูกตัดสินไปแล้วก่อนหน้า หากอินนิ่งสิ้นสุดลงในระหว่างโอเวอร์แรกเนื่องจากปัจจัยภายนอก เช่น สภาพอากาศไม่ดี การเดิมพันทั้งหมดจะเป็นโมฆะ เว้นแต่ผลจะถูกตัดสินได้ก่อนเกิดเหตุหยุดเกม
  • ในแมตช์ First Class ตลาดนี้จะใช้เฉพาะอินนิ่งแรกของแต่ละทีมเท่านั้น
  • แต้มพิเศษ (Extras) และรันลงโทษ (Penalty runs) ในโอเวอร์นั้น จะถูกนับรวมในการตัดสินผล
  • สำหรับการแข่งขันรูปแบบ The Hundred หนึ่งโอเวอร์จะมีการโยนถูกกติกา 5 ลูก ดังนั้นหนึ่งอินนิ่งจะประกอบด้วย 20 โอเวอร์ ส่วนกติกาอื่น ๆ ใช้เหมือนกับรูปแบบจำกัดโอเวอร์ทั่วไป

ตลาดโอเวอร์

จำนวนรันในโอเวอร์ที่กำหนด

  • จะมีการทำคะแนนกี่รันในโอเวอร์ที่ระบุ
  • โอเวอร์ที่ระบุต้องถูกเล่นจนจบเพื่อให้การเดิมพันใช้ได้ เว้นแต่ผลเดิมพันถูกตัดสินไปแล้วก่อนนั้น หากอินนิ่งจบลงระหว่างโอเวอร์นั้น จะถือว่าโอเวอร์นั้นจบแล้ว ยกเว้น อินนิ่งจบลงเพราะปัจจัยภายนอก เช่น สภาพอากาศไม่ดี ในกรณีนั้นการเดิมพันทั้งหมดจะเป็นโมฆะ เว้นแต่ผลจะถูกตัดสินไปแล้วก่อน
  • หากโอเวอร์นั้น ไม่เริ่มต้นเลย ไม่ว่าด้วยเหตุผลใด การเดิมพันทั้งหมดจะเป็นโมฆะ
  • แต้มพิเศษ (extras) และแต้มลงโทษ (penalty runs) ในโอเวอร์นั้นจะถูกนับรวมในการตัดสินผล ยกเว้น กรณีที่แต้มลงโทษทำให้เกมหรืออินนิ่งจบลงก่อนเริ่มโยนลูกในโอเวอร์นั้น แบบนี้โอเวอร์นั้นจะถือเป็นโมฆะ
  • ถ้ามีการรันเอาต์เกิดขึ้นในช่วงที่ผู้ขว้างกำลังวิ่งเตรียมโยน (run-up) เพื่อจบการแข่งขัน และยังไม่มีการขว้างลูกในโอเวอร์นั้นเลย การเดิมพันจะเป็นโมฆะ
  • สำหรับการแข่งขัน The Hundred หนึ่งโอเวอร์จะประกอบด้วยลูกที่ถูกกติกา 5 ลูก ทำให้อินนิ่งเต็มหนึ่งอินนิ่งมี 20 โอเวอร์ โดยกติกาอื่น ๆ เหมือนกับรูปแบบจำกัดโอเวอร์ทั่วไป

จำนวนรันที่ทำได้ในโอเวอร์ที่กำหนดแบบเจาะจง

  • จะมีการทำคะแนนทั้งหมดกี่รันในโอเวอร์ที่ระบุ
  • กติกาเหมือนกับกติกาในตลาด “จำนวนรันในโอเวอร์ที่กำหนด”

ขอบในโอเวอร์“ X ” มีการตีขอบสนามในโอเวอร์ที่กำหนดหรือไม่

  • กติกาเหมือนกับกติกาในตลาด “จำนวนรันในโอเวอร์ที่กำหนด”
  • นับเฉพาะการตีขอบสนามที่เกิดจากการตีลูกด้วยไม้ของผู้เล่น (ไม่ว่าจะเป็นลูกถูกกติกาหรือไม่ก็ตาม) การได้แต้มจากการขว้างพลาด (overthrows), การวิ่งครบสี่รัน และแต้มพิเศษ จะไม่นับเป็นการตีขอบสนาม

วีคเก็ตในโอเวอร์“ X ” จะมีการออกในโอเวอร์ที่กำหนดหรือไม่

  • กติกาเหมือนกับกติกาในตลาด “จำนวนรันในโอเวอร์ที่กำหนด”  ยกเว้นกรณี หากมีการรันเอาต์เกิดขึ้นในช่วงที่ผู้ขว้างกำลังวิ่งเตรียมโยน (run-up) จะถือว่ามีการออกเกิดขึ้นในโอเวอร์นั้น
  • สำหรับการตัดสินผลการเดิมพัน จะนับการออกทุกรูปแบบ รวมถึงการออกเพราะวิ่งไม่ทันด้วย - ผู้ตีที่ออกจากการตีเนื่องจากบาดเจ็บ จะ ไม่นับว่าออก - หากผู้ตีถูกตัดสิทธิ์เพราะใช้เวลาเข้าสนามช้าเกินไป หรือถูกระบุให้ออกจากการแข่งขัน ผู้เล่นจะถือว่าออกในลูกก่อนหน้า ดังนั้น การออกจากการตีเพราะบาดเจ็บ จะไม่ถือว่าเป็นการออก ในตลาดนี้

  • ในแมตช์ประเภท First Class ตลาดนี้จะใช้เฉพาะอินนิ่งแรกของแต่ละทีมเท่านั้น

  • จะทำคะแนนได้กี่รันจากการส่งลูกที่ระบุ
  • ผลการเดิมพันจะตัดสินจากจำนวนรันที่ถูกบวกเข้ายอดรวมของทีมจากลูกนั้น
  • สำหรับการตัดสินผลเดิมพัน ลูกผิดกติกาทั้งหมดจะนับเป็นหนึ่งการขว้าง ตัวอย่าง: หากโอเวอร์เริ่มด้วยลูกไวด์ ลูกนั้นจะนับเป็นลูกแรกและได้ 1 รัน ถึงแม้ยังไม่มีการขว้างลูกที่ถูกกติกา ลูกถัดไปจะถือเป็นลูกที่สองของโอเวอร์ หากลูกนั้นนำไปสู่การได้ตีฟรี (Free Hit) หรือ free hit ต้องขว้างใหม่เพราะลูกผิดกติกา รันที่ได้จากลูกตีฟรีนั้น จะไม่นับ ในตลาดนี้
  • รันทั้งหมดไม่ว่าจะได้จากไม้นักตีหรือไม่ จะถูกนับรวม ตัวอย่าง: ลูกไวด์ที่แล้วผู้ตีวิ่งเพิ่มได้ 3 รัน จะเท่ากับ 4 รันจากลูกนั้น กรณีมีแต้มลงโทษเกิดขึ้นในจังหวะลูก เช่น ลูกบอลไปโดนหมวกของฟิลเดอร์ในสนาม ได้ 5 แต้มลงโทษ และผู้ตีวิ่งได้อีก 1 รัน รวมเป็น 6 รันจากลูกนั้น
  • สำหรับการแข่งขันแบบ The Hundred - หนึ่งโอเวอร์มีลูกถูกกติกา 5 ลูก รวมอินนิ่งละ 20 โอเวอร์ - ถ้าไม่มีลูกผิดกติกา ลูกที่ 5 ของอินนิ่งจะแสดงเป็น “จำนวนรันจากลูกที่ 5 โอเวอร์แรก” และลูกที่ 6 จะเป็น “จำนวนรันจากลูกที่ 1 โอเวอร์ที่สอง” - หากมีลูกผิดกติกาใน 5 ลูกแรก ลูกที่ 6 ของอินนิ่งจะแสดงเป็น “จำนวนรันจากลูกที่ 6 โอเวอร์แรก” - กติกาอื่น ๆ เหมือนการแข่งขันแบบจำกัดโอเวอร์ทั่วไป

จำนวนรันจากลูกที่กำหนดแบบระบุจำนวนแน่นอน

  • จะมีการทำคะแนนทั้งหมดกี่รันจากลูกที่ระบุ
  • กติกาเหมือนกับกติกาในตลาด “จำนวนรันจากลูกที่กำหนด”

จำนวนรันตอนที่วิเก็ตที่กำหนดล้ม

  • ทายว่าทีมฝ่ายตีจะมีคะแนนทั้งหมดกี่รันในตอนที่วิเก็ตที่ระบุล้ม (ผู้ตีคนที่กำหนดถูกทำให้ออก)
  • ถ้าอินนิ่งจบลงก่อนที่วิเก็ตที่ระบุกำหนดจะล้ม การเดิมพันจะตัดสินตามจำนวนรันสุดท้ายของทีมนั้นในอินนิ่งนั้น
  • ผู้ตีที่ออกจากการตีเพราะบาดเจ็บไม่นับว่าเป็นการออก สำหรับการตัดสินเดิมพันนี้
  • ในแมตช์แบบจำกัดจำนวนโอเวอร์ การเดิมพันจะเป็นโมฆะ หากไม่สามารถเล่นได้อย่างน้อย 80% ของโอเวอร์ที่กำหนดในอินนิ่งใดอินนิ่งหนึ่ง เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ เว้นแต่ผลการเดิมพันตัดสินได้แล้ว หรือสามารถตัดสินได้ในภายหลัง หากคะแนนผ่านเส้นเดิมพันที่วางไว้แล้ว หรือวิเก็ตที่ระบุล้มลงแล้ว จะถือว่าผลเดิมพันตัดสินแล้ว
  • ในแมตช์ First Class ที่ผลออกมาเป็นเสมอ การเดิมพันจะเป็นโมฆะ หากจำนวนโอเวอร์ทั้งหมดที่เล่นน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันได้ถูกตัดสินก่อนหน้านั้นแล้ว

วิธีการออกของวิเก็ตถัดไป

  • ทายว่าผู้ตีคนต่อไปจะออกด้วยวิธีใด
  • ผลการเดิมพันจะตัดสินตามวิธีการออกของวิเก็ตถัดไปที่เกิดขึ้น
  • กรณีผู้ตีออกจากการตีเพราะบาดเจ็บ จะ ไม่นับว่าออก หากผู้ตีถูกระบุให้ออกจากเกมโดยตรง (retired out) การเดิมพันทั้งหมดจะเป็น โมฆะ หากวิเก็ตที่ระบุไม่เกิดขึ้น การเดิมพันทั้งหมดจะเป็น โมฆะ
  • กรณี “ขว้างแล้วรับเอง” (Caught & Bowled) จะถือว่าเป็นการจับออกโดยฟิลเดอร์ (นับรวมในหมวดการรับจับออก)

จำนวนรันที่ผู้ตีทำได้

  • ทายว่าผู้ตีที่ระบุจะทำคะแนนกี่รัน
  • หากผู้ตีจบอินนิ่งโดยยังไม่ออก จำนวนรันสุดท้ายของเขาจะถือเป็นผลการเดิมพัน หากผู้ตีไม่ได้ออกมาตีเลย การเดิมพันจะเป็นโมฆะ
  • ในแมตช์แบบจำกัดโอเวอร์ การเดิมพันจะเป็นโมฆะ หากไม่สามารถเล่นได้อย่างน้อย 80% ของโอเวอร์ที่กำหนดในอินนิ่งใดอินนิ่งหนึ่ง เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ เว้นแต่ผลการเดิมพันถูกตัดสินไปแล้ว หรือสามารถตัดสินได้ต่อไป
  • ผลการเดิมพันจะถือว่าตัดสินแล้ว หากคะแนนเกินเส้นเดิมพันที่วางไว้ หรือผู้ตีถูกทำให้ออก
  • ในแมตช์ First Class ที่ผลออกมาเป็นเสมอ การเดิมพันจะเป็นโมฆะ หากเล่นโอเวอร์รวมกันน้อยกว่า 200 โอเวอร์ เว้นแต่ผลเดิมพันถูกตัดสินแล้ว
  • สำหรับการเดิมพันก่อนเริ่มเกม จะนับเฉพาะอินนิ่งแรกของผู้ตีเท่านั้น
  • คะแนนที่ทำได้ใน ซูเปอร์โอเวอร์ จะ ไม่นับรวม

จำนวนรันรวมของผู้ตีที่ระบุ

  • ทายว่าผู้ตีที่ระบุไว้จะทำคะแนนรวมกันได้ทั้งหมดกี่รัน
  • ใช้กติกาเดียวกับตลาด “จำนวนรันของผู้ตี” และหากผู้ตีคนใดคนหนึ่งในรายชื่อไม่ได้ออกมาตี การเดิมพันจะเป็นโมฆะ ยกเว้นผลการเดิมพันถูกตัดสินไปแล้ว หรือสามารถตัดสินได้ในภายหลัง

จำนวนการตีได้สี่รันของผู้ตี

  • ทายว่าผู้ตีที่ระบุจะตีได้สี่รันทั้งหมดกี่ครั้ง
  • หากผู้ตีจบอินนิ่งโดยยังไม่ออก จำนวนครั้งที่ตีได้สี่รันที่ทำไว้จะถือเป็นผลสุดท้าย หากผู้ตีไม่ได้ออกมาตีเลย การเดิมพันจะเป็นโมฆะ
  • หากผู้ตีออกจากการตีเพราะบาดเจ็บแต่กลับมาตีต่อภายหลัง จะนับรวมจำนวนครั้งที่ตีสี่รันทั้งหมดในอินนิ่งนั้น หากผู้ตีไม่กลับมาตีอีก ผลการเดิมพันจะใช้จำนวนครั้งที่ตีสี่รัน ณ เวลาที่ออกเพราะบาดเจ็บ
  • ในแมตช์แบบจำกัดโอเวอร์ การเดิมพันจะเป็นโมฆะหากไม่สามารถเล่นได้อย่างน้อย 80% ของโอเวอร์ในอินนิ่งใดอินนิ่งหนึ่ง เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ เว้นแต่ผลการเดิมพันถูกตัดสินแล้วหรือสามารถตัดสินได้ภายหลัง
  • ผลการเดิมพันจะถือว่าตัดสินแล้ว หากจำนวนครั้งที่ตีสี่รันเกินเส้นเดิมพันที่วางไว้ หรือผู้ตีถูกทำให้ออก
  • ในแมตช์ First Class ที่ผลออกเป็นเสมอ การเดิมพันจะเป็นโมฆะหากจำนวนโอเวอร์รวมกันน้อยกว่า 200 โอเวอร์ เว้นแต่ผลเดิมพันถูกตัดสินแล้ว
  • จะนับเฉพาะการตีได้สี่รันจากไม้ของผู้ตีเท่านั้น ไม่ว่าลูกจะถูกกติกาหรือไม่ การได้สี่รันจากการขว้างพลาด การวิ่งครบสี่รัน หรือรันพิเศษ จะไม่นับ
  • การเดิมพันก่อนเริ่มเกม จะนับเฉพาะอินนิ่งแรกของผู้ตีเท่านั้น
  • การตีสี่รันในซูเปอร์โอเวอร์ จะไม่นับรวม

จำนวนการตีได้หกรันของผู้ตี

  • ทายว่าผู้ตีที่ระบุจะตีหกรันได้ทั้งหมดกี่ครั้ง
  • หากผู้ตีจบอินนิ่งโดยยังไม่ออก จำนวนครั้งที่ตีหกรันที่ทำไว้จะถือเป็นผลเดิมพันสุดท้าย หากผู้ตีไม่ได้ออกมาตีเลย การเดิมพันจะเป็นโมฆะ
  • หากผู้ตีออกจากการตีเพราะบาดเจ็บและกลับมาตีต่อภายหลัง จะนับรวมจำนวนครั้งที่ตีหกรันทั้งหมดในอินนิ่งนั้น หากไม่กลับมาตีอีก ผลจะเป็นจำนวนครั้งที่ตีหกรัน ณ ตอนออกเพราะบาดเจ็บ
  • ในแมตช์แบบจำกัดโอเวอร์ หากไม่สามารถเล่นได้อย่างน้อย 80% ของโอเวอร์ของอินนิ่งใดอินนิ่งหนึ่งเนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ การเดิมพันจะเป็นโมฆะ เว้นแต่ผลได้ถูกตัดสินแล้วหรือสามารถตัดสินได้
  • ผลการเดิมพันจะถือว่าตัดสิน หากจำนวนครั้งที่ตีหกรันถึงหรือเกินเส้นเดิมพันที่วางไว้ หรือผู้ตีถูกทำให้ออก
  • ในแมตช์ First Class หากแข่งขันน้อยกว่า 200 โอเวอร์และผลยังไม่ถูกตัดสิน การเดิมพันจะเป็นโมฆะ
  • จะนับเฉพาะหกรันที่ได้จากการตีด้วยไม้เท่านั้น ไม่ว่าลูกจะถูกกติกาหรือไม่ การได้รันจากการขว้างพลาดหรือรันพิเศษ จะไม่นับเป็นหกรัน
  • สำหรับการเดิมพันก่อนเริ่มเกม จะนับเฉพาะอินนิ่งแรกของผู้ตีเท่านั้น
  • การตีหกรันในซูเปอร์โอเวอร์ จะไม่นับรวม

ผู้ตีทำสถิติแต้มตามที่กำหนดหรือไม่

  • ผู้ตีที่ระบุจะสามารถทำคะแนนถึงระดับที่กำหนดไว้หรือไม่ เช่น 50 หรือ 100 รัน
  • กติกาอื่น ๆ ใช้เช่นเดียวกับตลาด “จำนวนรันของผู้ตี”

จำนวนลูกที่ผู้ตีเผชิญหน้า

  • ทายว่าผู้ตีที่ระบุจะเผชิญหน้ากับลูกขว้างทั้งหมดกี่ลูก
  • การนับจำนวนลูกจะอ้างอิงตามบันทึกคะแนนอย่างเป็นทางการ โดย ลูกเสียที่ออกนอกแนว (wide) จะไม่นับเป็นลูกที่ผู้ตีเผชิญหน้า แต่ ลูกผิดกติกาที่โยนซ้ำ (no-ball) จะนับเป็นลูกที่ผู้ตีเผชิญหน้า
  • หากผู้ตีออกจากการตีเพราะบาดเจ็บ และกลับมาตีต่อ จะนับรวมจำนวนลูกทั้งหมดที่เผชิญหน้าในอินนิ่งนั้น หากไม่กลับมาตี จำนวนลูกที่เผชิญหน้าก่อนบาดเจ็บจะถือเป็นผลสุดท้าย
  • ในแมตช์แบบจำกัดโอเวอร์ การเดิมพันจะเป็นโมฆะ หากไม่สามารถเล่นได้อย่างน้อย 80% ของโอเวอร์ในอินนิ่งใดอินนิ่งหนึ่งเนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ เว้นแต่ผลการเดิมพันถูกตัดสินแล้ว หรือสามารถตัดสินได้ภายหลัง
  • ผลการเดิมพันจะถือว่าตัดสิน เมื่อจำนวนลูกที่เผชิญหน้าถึงหรือเกินเส้นเดิมพันที่วางไว้ หรือเมื่อผู้ตีถูกทำให้ออก
  • ในแมตช์ First Class หากเล่นรวมกันน้อยกว่า 200 โอเวอร์ และผลยังไม่ถูกตัดสิน การเดิมพันจะเป็นโมฆะ
  • การเดิมพันก่อนเริ่มเกม จะนับเฉพาะอินนิ่งแรกของผู้ตีเท่านั้น
  • จำนวนลูกที่เผชิญหน้าในซูเปอร์โอเวอร์ จะไม่นับรวม

รูปแบบการออกของผู้ตีที่ระบุ

  • ทายว่าผู้ตีที่ระบุจะออกด้วยวิธีใด
  • หากผู้ตีที่ระบุไม่ถูกทำให้ออกเลย การเดิมพันทั้งหมดจะเป็นโมฆะ
  • หากผู้ตีออกจากการตีเพราะบาดเจ็บและไม่กลับมาตีอีก การเดิมพันทั้งหมดจะเป็นโมฆะ แต่หากผู้ตีกลับมาตีภายหลังและถูกทำให้ออก การเดิมพันยังใช้ได้
  • กรณี “ขว้างแล้วรับเอง” จะนับเป็นการจับออกโดยฟิลเดอร์

จำนวนวิเก็ตที่ผู้ขว้างทำได้

  • ทายว่าผู้ขว้างที่ระบุจะสามารถทำวิเก็ตได้ทั้งหมดกี่ครั้ง
  • หากผู้ขว้างไม่ได้ลงขว้างเลย การเดิมพันจะเป็นโมฆะ
  • ในแมตช์แบบจำกัดโอเวอร์ การเดิมพันจะเป็นโมฆะ หากไม่สามารถเล่นได้อย่างน้อย 80% ของโอเวอร์ในอินนิ่งที่เกี่ยวข้อง เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ เว้นแต่ผลการเดิมพันได้ถูกตัดสินแล้ว หากจำนวนวิเก็ตที่ทำได้ถึงหรือเกินเส้นเดิมพัน การเดิมพันจะถือว่าได้ผลแล้ว
  • ในแมตช์ First Class ที่ผลออกเป็นเสมอ การเดิมพันจะเป็นโมฆะ หากแข่งขันรวมกันน้อยกว่า 200 โอเวอร์ เว้นแต่ผู้ขว้างคนนั้นจะขว้างครบอินนิ่งของตนแล้ว
  • สำหรับการเดิมพันก่อนเริ่มแข่ง จะนับเฉพาะอินนิ่งแรกของผู้ขว้างเท่านั้น
  • วิเก็ตที่ได้ใน ซูเปอร์โอเวอร์ จะ ไม่นับรวม

จำนวนรันที่ผู้ขว้างเสีย

  • ทายว่าผู้ขว้างที่ระบุจะเสียรันทั้งหมดกี่รัน
  • การนับรันให้ตรงตามใบบันทึกคะแนน: ลูกไวด์ และ โนบอล นับเป็นรันที่เสีย แต่ บาย, เลกบาย และ แต้มลงโทษ ไม่นับรวม
  • หากผู้ขว้างไม่ได้ลงขว้างเลย การเดิมพันจะเป็นโมฆะ
  • ในแมตช์แบบจำกัดโอเวอร์ การเดิมพันจะเป็นโมฆะ หากไม่สามารถเล่นได้อย่างน้อย 80% ของโอเวอร์ที่กำหนดในอินนิ่งที่เกี่ยวข้อง เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ เว้นแต่ผลการเดิมพันถูกตัดสินแล้ว โดยจะถือว่าตัดสินแล้วหากคะแนน ผ่านเส้นเดิมพัน ที่วางไว้
  • จะถือว่าผลการเดิมพันตัดสินแล้ว หากคะแนน ผ่านเส้นเดิมพัน ที่วางไว้ หรือเมื่อผู้ตีถูกทำให้ออก
  • ในแมตช์ประเภท First Class ที่ผลออกเป็นเสมอ การเดิมพันจะเป็นโมฆะ หากเล่นรวมกันน้อยกว่า 200 โอเวอร์ เว้นแต่ผลการเดิมพันถูกตัดสินไปแล้วก่อนหน้า
  • สำหรับการเดิมพันก่อนเริ่มเกม จะนับเฉพาะอินนิ่งแรกของผู้ขว้างเท่านั้น
  • วิเก็ตที่เกิดขึ้นในซูเปอร์โอเวอร์ จะไม่นับรวม

ทั้งสองทีมจะทำได้ “X” รันหรือไม่

  • ทั้งสองทีมจะสามารถทำคะแนนได้ถึงจำนวนรันที่กำหนดหรือไม่
  • ยึดตามกติกาอินนิ่งรัน หากในแต่ละอินนิ่งมีการขว้างอย่างน้อย 80% ของจำนวนโอเวอร์ที่กำหนดไว้ ณ ตอนวางเดิมพัน อินนิ่งนั้นจะถือว่าเสร็จสมบูรณ์ และตลาดนี้จะตัดสินผลตามนั้น
  • ในแมตช์ First Class ที่จบด้วยผลเสมอ การเดิมพันจะเป็นโมฆะ หากในอินนิ่งแรกของทีมใดทีมหนึ่งมีการขว้างน้อยกว่า 100 โอเวอร์ เว้นแต่ผลเดิมพันถูกตัดสินไปแล้ว จะนับเฉพาะรันที่ทำได้ในอินนิ่งแรกเท่านั้น หากทีมประกาศจบอินนิ่งเอง อินนิ่งนั้นจะถือว่าเสร็จสมบูรณ์สำหรับการตัดสินเดิมพัน

ผู้ตีที่ระบุคนใดคนหนึ่งจะออกด้วยวิธีที่กำหนดหรือไม่

  • ผู้ตีที่ระบุคนใดคนหนึ่ง (อย่างน้อยหนึ่งคน) จะถูกทำให้ออกด้วยวิธีที่กำหนดไว้หรือไม่ ตัวอย่าง: ผู้เล่น A หรือ B – วิธีการออกที่กำหนด – อินนิ่งแรก
  • การเดิมพันจะตัดสินผลไม่ว่า ผู้ตีทั้งสองจะยังไม่ออก หรือออกเพราะบาดเจ็บและไม่ได้กลับมาตีอีก เมื่อจบอินนิ่งก็ตาม

ผู้ตีทั้งสองคนจะออกด้วยวิธีที่กำหนดหรือไม่

  • ผู้ตีที่ระบุทั้งสองคนจะถูกทำให้ออกด้วยวิธีการที่กำหนดไว้หรือไม่ ตัวอย่าง: ผู้เล่น A และ B – วิธีการออกที่กำหนด – อินนิ่งแรก
  • การเดิมพันจะตัดสินผล แม้ว่าผู้ตีคนใดคนหนึ่งหรือทั้งสองคนจะยังไม่ออก หรือออกเพราะบาดเจ็บและไม่กลับมาตีอีกเมื่ออินนิ่งสิ้นสุด

ผู้ตีทั้งสองคนต้องทำได้ “X” รันในโอเวอร์ที่กำหนด

  • ผู้ตีทั้งสองคนจะทำคะแนนได้ตามจำนวนที่กำหนดในโอเวอร์นั้นหรือไม่ ตัวอย่าง: โอเวอร์ที่ 6 – ผู้เล่น A และ ผู้เล่น B ต้องทำมากกว่า 10.5 รันในอินนิ่งแรก
  • โอเวอร์ที่กำหนดต้องเล่นจบเพื่อให้การเดิมพันใช้ได้ เว้นแต่ผลเดิมพันถูกตัดสินไปแล้ว ถ้าอินนิ่งจบระหว่างโอเวอร์ จะถือว่าโอเวอร์นั้นจบแล้ว แต่หากอินนิ่งจบเพราะปัจจัยภายนอก เช่น สภาพอากาศไม่ดี การเดิมพันจะเป็นโมฆะ เว้นแต่ผลถูกตัดสินแล้วก่อนหน้านั้น
  • หากโอเวอร์ที่กำหนด ไม่ได้เริ่มเล่นเลย การเดิมพันจะเป็นโมฆะ
  • ต้องเป็นคะแนนที่เกิดจากการตีบอลเท่านั้นจึงจะนับเป็นผลเดิมพัน
  • การเดิมพันจะตัดสินผล แม้ว่าผู้ตีคนใดคนหนึ่งหรือทั้งสองคนจะถูกทำให้ออก หรือออกเพราะบาดเจ็บก่อนถึงโอเวอร์นั้น

ผู้ตีทั้งสองคนต้องตีได้ขอบสนามในโอเวอร์ที่กำหนด

  • ทั้งสองผู้ตีจะตีได้ขอบสนาม (Boundary) ในโอเวอร์นั้นหรือไม่
  • กติกาเหมือนกับตลาด “ผู้ตีทั้งสองคนต้องทำได้ X รันในโอเวอร์ที่กำหนด”
  • การตีได้ทั้งสี่รัน (Four) และหกรัน (Six) จะนับเป็นการตีขอบสนาม และจะนับเฉพาะการตีที่มาจากไม้ของผู้ตีเท่านั้น ไม่ว่าจะเป็นลูกถูกกติกาหรือไม่ก็ตาม การได้แต้มจากการขว้างพลาด การวิ่งครบสี่รัน และแต้มพิเศษ จะไม่นับเป็นการตีขอบสนาม

ในโอเวอร์ที่กำหนด จะมีทั้งสี่รันและหกรันเกิดขึ้นหรือไม่

  • จะมีทั้งการตีได้สี่รัน (Four) และการตีได้หกรัน (Six) ในโอเวอร์นั้นหรือไม่
  • โอเวอร์ที่กำหนดต้องเล่นจบเพื่อให้การเดิมพันใช้ได้ เว้นแต่ผลเดิมพันถูกตัดสินไปแล้วก่อนหน้า ถ้าอินนิ่งสิ้นสุดระหว่างโอเวอร์ จะถือว่าโอเวอร์นั้นจบแล้ว แต่ถ้าอินนิ่งจบลงเพราะปัจจัยภายนอก เช่น สภาพอากาศไม่ดี การเดิมพันจะเป็นโมฆะ เว้นแต่ผลได้ถูกตัดสินแล้วก่อนการหยุดเกม
  • หากโอเวอร์ที่กำหนด ไม่เริ่มเล่นเลย การเดิมพันจะเป็นโมฆะ
  • จะนับเฉพาะการตีสี่รันและหกรันที่เกิดจากการตีด้วยไม้ของผู้ตีเท่านั้น ไม่ว่าจะเป็นลูกถูกกติกาหรือไม่ การได้แต้มจากการขว้างพลาด การวิ่งครบสี่รัน และแต้มพิเศษ จะไม่นับเป็นสี่หรือหกรันในตลาดนี้

ผู้ตีและผู้ขว้างที่ระบุ จะทำสถิติที่กำหนดสำเร็จทั้งคู่หรือไม่

  • ผู้ตีที่ระบุ และผู้ขว้างที่ระบุ จะสามารถทำตามเป้าหมายที่กำหนดไว้หรือไม่ (เช่น ผู้ตีถึง 50 รัน และผู้ขว้างได้ 2 วิเก็ต)
  • กติกาเกี่ยวกับผู้ตีใช้ตามตลาด “จำนวนรันของผู้ตี” ในแมตช์ First Class จะนับเฉพาะรันในอินนิ่งแรกเท่านั้น
  • สำหรับผู้ขว้าง — หากไม่ได้ลงขว้าง จะถือว่าได้ 0 วิเก็ต ในแมตช์ First Class จะนับเฉพาะวิเก็ตในอินนิ่งแรกเท่านั้น
  • ในแมตช์แบบจำกัดโอเวอร์ การเดิมพันจะเป็นโมฆะ หากไม่สามารถเล่นได้อย่างน้อย 80% ของโอเวอร์ในอินนิ่งที่เกี่ยวข้อง เนื่องจากปัจจัยภายนอก เช่น สภาพอากาศ เว้นแต่ผลการเดิมพันถูกตัดสินแล้ว
  • ในแมตช์ First Class ที่จบด้วยผลเสมอ การเดิมพันจะเป็นโมฆะ หากแข่งขันรวมกันน้อยกว่า 200 โอเวอร์ เว้นแต่ผู้เล่นทำผลงานครบตามอินนิ่งการขว้างของตนแล้ว หากสถิติที่กำหนดถูกทำสำเร็จตามเส้นเดิมพันแล้ว การเดิมพันถือว่าได้ผล
  • ในแมตช์ First Class จะนับเฉพาะวิเก็ตและรันในอินนิ่งแรกเท่านั้น สถิติที่เกิดขึ้นในซูเปอร์โอเวอร์ จะไม่นับรวม

ผู้ตีทั้งสองคนจะถึงสถิติที่กำหนดหรือไม่

  • ผู้ตีที่ระบุทั้งสองคนจะสามารถทำคะแนนถึงเป้าหมายที่กำหนดไว้หรือไม่ (เช่น ทั้งสองถึง 50 รัน)
  • กติกาเหมือนกับตลาด “จำนวนรันรวมของผู้ตีที่ระบุ”

จำนวนรันจากลูกที่ต่อเนื่องกันตามที่กำหนด

  • จะมีการทำคะแนนกี่รันจากแต่ละลูกตามลำดับที่กำหนด ตัวอย่าง: จำนวนรันจากลูกที่ 31 ถึงลูกที่ 35 ของทีม A
  • กติกาเหมือนกับตลาด “จำนวนรันจากลูกที่กำหนด” แต่ในตลาดนี้ ต้องได้จำนวนรันตามที่กำหนดใน ทุกลูกที่ระบุไว้ ถึงจะถือว่าผ่านเงื่อนไข

จะมีผู้ตีถูกทำให้ออกในลูกที่กำหนดหรือไม่

  • ทายว่าจะมีการออกเกิดขึ้นในลูกที่กำหนดหรือไม่
  • ลูกที่กำหนดต้องมีการขว้างครบจึงจะใช้ผลเดิมพันได้ - การออกทุกรูปแบบจะนับรวม (รวมถึงการออกเพราะวิ่งไม่ทัน) - หากผู้ตีออกจากการตีเพราะบาดเจ็บ จะ ไม่นับว่าออก - หากผู้ตีถูกตัดสิทธิ์เพราะเข้าสนามช้าเกินไป หรือถูกระบุให้ออกจากการแข่งขัน จะถือว่าการออกนั้นเกิดขึ้นในลูกก่อนหน้า
